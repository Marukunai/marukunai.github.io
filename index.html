Lo que tengo en ejecución

proc/01
Poker Online — Backend
SPRING BOOT · WEBSOCKET · JWT · MYSQL
en desarrollo código privado

Backend de un Texas Hold'em multijugador en tiempo real — 207 clases Java organizadas en dominios (torneos, amigos, logros, moderación, bots). Autenticación JWT, mesas por WebSocket, motor de bots con IA, torneos individuales y por equipos, moderación con sanciones automáticas, modo espectador, mesas privadas y un sistema de amigos completo con chat privado y transferencia de fichas. 53 logros distintos, estadísticas y ranking, API testeada con Postman.

proc/02 Blackjack Pro — Motor de Juego ↗
PYTHON · PYGAME · PYTEST
estable

Blackjack de casino en Python con Pygame: de 1 a 8 mazos, todas las jugadas reales (double down, split, surrender, insurance), un sistema de pistas con estrategia básica y contador de cartas Hi-Lo visual, animaciones y estadísticas de sesión. Arquitectura por capas (core/engine/ai/ui) con tests unitarios en pytest.

proc/03
App de Anime — Full Stack
ANDROID · SPRING BOOT · JPA
en desarrollo

Dos repos, un proyecto: animeDB es una API en Spring Boot con JPA (controladores, DTOs, repositorios) para animes, vídeos, usuarios y favoritos; animeApp es el cliente Android que la consume vía Retrofit, con login, favoritos animados, galería y reproductor a pantalla completa.

proc/04 Web Cooperativa Musical ↗
NODE.JS · API SPOTIFY · MÉTRICAS
estable

Landing para tres artistas con datos en vivo de Spotify (top tracks), middleware propio de estadísticas de visitas y un panel /stats para seguir el rendimiento del sitio.

proc/05 Web Artista — J Rodriguez ↗
YOUTUBE DATA API · FORMSPREE · SIN BACKEND
en desarrollo

Sitio 100% estático para un artista de reggaetón: los últimos vídeos se actualizan solos vía la YouTube Data API, con formulario de contacto y newsletter conectados a Formspree, analítica sin cookies (GoatCounter), páginas de privacidad y SEO cuidado con sitemap y 404 personalizada — todo sin servidor ni coste de hosting.

proc/06 Identificador de Tipos Pokémon ↗
JAVA · CLI · LÓGICA PURA
estable

Nació de un problema muy concreto: en una ROM con tipos aleatorios, el juego nunca te dice el tipo real del rival. Metí a mano la tabla completa de efectividades entre los 18 tipos y, a partir de lo que ves en combate ("súper efectivo", "no muy efectivo"...), el programa va descartando tipos hasta acotar cuál es el de verdad.
